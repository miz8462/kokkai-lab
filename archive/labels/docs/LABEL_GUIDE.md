# ラベル定義 v2(theme: 消費税)

## stance(立場) 1つだけ選ぶ(コード a〜e)
基準: 話者が、消費税の税率・制度そのものについて、本文で明示的に求めている方向。
本文に書かれていないことは、話者の党派や普段の主張から推測しない。
- a 減税・廃止: 減税・廃止・ゼロ・税率引き下げを求める、または、実施しないことを責める・促す
  (例: 「五％に引き下げるべき」「なぜ減税を検討しないのか」)
- b 現行維持: 現行の税率・制度を維持すべき、減税・廃止そのものに反対と明示している
- c 引き上げ: 税率の引き上げを主張・容認すると明示している
- d 条件付き・不明確: 立場に触れているが、方向が定まらない・別の方式を主張している
  (例: 「食料品だけでなく全品目の単一税率の引き下げを」)
- e 該当なし: 上のどれにも当てはまらない。次の場合を含む
  - 事実の説明、手続き的な質問、委員長報告
  - 減税案の設計・影響・財源・副作用を問う、または批判する
  - 消費税を批判・否定的に評価しているが、減税などの要求は明示していない
    → 傾向が読み取れるときは、note に「暗示:減税寄り」のように書く
  - 消費税ではなく、別の政策(給付付き税額控除、法人税、財政規律など)を主張している

## 根拠のルール
- a〜d は、「求めている」と読める語句が、この段落・前の段落・次の段落のどこかにある場合だけ付ける
- 根拠にした語句と、どの段落のものか(本文/前/次)を note に書く
- 根拠が示せなければ e にする
